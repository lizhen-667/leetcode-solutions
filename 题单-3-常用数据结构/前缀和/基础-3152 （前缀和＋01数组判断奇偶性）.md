
> 核心思想：**前缀和思想 + 01数组判断区间内是否存在“相邻元素奇偶性相同”**  
> 预处理 `O(n)`，每次查询 `O(1)`，总时间复杂度 `O(n + q)`。

---

## 1. 题意概括

给出数组 `nums` 与若干查询：

```cpp
queries[i] = [Li, Ri]
```

对于每个查询，判断闭区间 `[Li, Ri]` 是否为**特殊数组**。

特殊数组的定义：

> **数组中每一对相邻元素的奇偶性都必须不同。**

例如：

```text
[3, 4, 1, 2]
 奇 偶 奇 偶
```

相邻元素的奇偶性都不同，因此是特殊数组。

而：

```text
[3, 4, 4, 2]
 奇 偶 偶 偶
```

其中：

```text
4 和 4 → 奇偶性相同
```

因此不是特殊数组。

---

# 2. 核心思路

直接对每一个查询 `[L, R]` 遍历区间，检查每一对相邻元素是否满足要求，会产生大量重复计算。

因此采用**前缀统计**的思想：

> 先预处理整个 `nums`，记录每个位置之前一共出现了多少次“相邻元素奇偶性相同”。

这样查询一个区间时，只需要比较两个前缀统计值即可。

---

## 2.1 构建 01 数组

对于 `nums` 中每一对相邻元素：

- 如果奇偶性**相同** → 记为 `1`
    
- 如果奇偶性**不同** → 记为 `0`
    

例如：

```text
nums = [3, 4, 4, 2, 5]

奇偶性：
       奇  偶  偶  偶  奇

相邻判断：
3 和 4 → 不同 → 0
4 和 4 → 相同 → 1
4 和 2 → 相同 → 1
2 和 5 → 不同 → 0
```

得到 01 数组：

```text
[0, 1, 1, 0]
```

这个 01 数组实际上是在记录：

> **哪些相邻位置违反了“奇偶性必须不同”的要求。**

---

## 2.2 构建前缀和数组

定义：

```cpp
vector<int> s(nums.size());
```

其中：

```text
s[i] 表示从 nums[0] 到 nums[i] 为止，
一共出现了多少次“相邻元素奇偶性相同”。
```

初始化：

```cpp
s[0] = 0;
```

原因：

> `nums[0]` 前面没有元素，因此不存在可以比较的相邻元素，所以问题数量为 `0`。

---

### 构建公式

```cpp
s[i + 1] = s[i] + (nums[i] % 2 == nums[i + 1] % 2);
```

其中：

```cpp
(nums[i] % 2 == nums[i + 1] % 2)
```

是一个布尔表达式：

```text
奇偶性相同 → true  → 1
奇偶性不同 → false → 0
```

因此：

```text
s[i + 1]
=
之前发现的问题数量
+
当前这一对相邻元素是否存在问题
```

---

## 2.3 为什么 `s` 的长度是 `nums.size()`，不是 `nums.size() + 1`？

这是本题非常容易混淆的地方。

这里定义的是：

```text
s[i] = nums[0..i] 范围内的问题数量
```

因此：

```text
nums：  3   4   4   2
下标：  0   1   2   3

s：     0   0   1   2
```

`nums` 有几个元素，`s` 就对应几个位置。

其中：

```text
s[0] = 0
```

表示到 `nums[0]` 为止，还没有发生任何相邻比较。

---

### 与普通前缀和的区别

普通前缀和通常定义为：

```cpp
prefix[i + 1] = prefix[i] + nums[i];
```

此时：

```text
prefix[i]
```

表示 `nums[0..i-1]` 的和，因此通常需要：

```cpp
n + 1
```

而本题采用的是：

```text
s[i] = nums[0..i] 中的问题数量
```

所以使用：

```cpp
n
```

即可。

> **前缀数组到底是 `n` 还是 `n+1`，取决于你对 `s[i]` 的定义，而不是固定规定。**

# 3. 查询判断

定义结果数组：

```cpp
vector<bool> ans(queries.size());
```

遍历每个查询：

```cpp
for(int i = 0; i < queries.size(); i++){
    auto& q = queries[i];
    ans[i] = s[q[0]] == s[q[1]];
}
```

其中：

```cpp
q[0] = L
q[1] = R
```

表示闭区间：

```text
[L, R]
```

---

## 3.1 为什么判断 `s[L] == s[R]`？

我们真正需要检查的是：

```text
nums[L]     和 nums[L+1]
nums[L+1]   和 nums[L+2]
...
nums[R-1]   和 nums[R]
```

也就是查询区间 `[L,R]` 内部的所有相邻关系。

而：

```cpp
s[R] - s[L]
```

恰好表示从 `L` 到 `R` 之间新增了多少次：

> “相邻元素奇偶性相同”。

因此：

```text
s[R] - s[L] == 0
```

表示：

> 区间 `[L,R]` 内没有出现相邻奇偶性相同。

也就是：

> 区间 `[L,R]` 是特殊数组。

为了简化代码：

```cpp
s[R] - s[L] == 0
```

可以直接写成：

```cpp
s[L] == s[R]
```

---

## 3.2 为什么查询使用闭区间 `[L,R]`？

题目中的：

```cpp
queries[i] = [L, R]
```

表示：

```text
nums[L], nums[L+1], ..., nums[R]
```

左右端点都包含。

例如：

```text
nums = [3, 4, 1, 2]
        0  1  2  3
```

查询：

```text
[1,3]
```

表示：

```text
4, 1, 2
```

需要检查：

```text
4 和 1
1 和 2
```

正好对应：

```cpp
s[1] 和 s[3]
```

所以代码：

```cpp
ans[i] = s[q[0]] == s[q[1]];
```

能够正确判断闭区间 `[L,R]`。

---

# 4. 代码展示

```cpp
class Solution {
public:
    vector<bool> isArraySpecial(vector<int>& nums, vector<vector<int>>& queries) {

        int n = nums.size();

        // s[i] 表示 nums[0] ~ nums[i] 中
        // 出现了多少次“相邻元素奇偶性相同”
        vector<int> s(n);

        s[0] = 0;

        // 构建前缀统计数组
        for (int i = 0; i < n - 1; i++) {
            s[i + 1] = s[i] + (nums[i] % 2 == nums[i + 1] % 2);
        }

        // 保存每个查询的结果
        vector<bool> ans(queries.size());

        for (int i = 0; i < queries.size(); i++) {

            auto& q = queries[i];

            int L = q[0];
            int R = q[1];

            // s[R] - s[L] == 0
            // 等价于 s[L] == s[R]
            ans[i] = s[L] == s[R];
        }

        return ans;
    }
};
```

# 5. 示例

```text
nums = [3, 4, 4, 2, 5]
```

奇偶性：

```text
       奇  偶  偶  偶  奇
```

01数组：

```text
       0   1   1   0
```

前缀统计：

```text
下标： 0   1   2   3   4
nums： 3   4   4   2   5
s：    0   0   1   2   2
```

### 查询 `[0,1]`

区间：

```text
[3,4]
```

判断：

```cpp
s[0] == s[1]
0 == 0
```

结果：

```text
true
```

因为：

```text
3 和 4 → 奇偶性不同
```

### 查询 `[0,2]`

区间：

```text
[3,4,4]
```

判断：

```cpp
s[0] == s[2]
0 == 1
```

结果：

```text
false
```

因为：

```text
4 和 4 → 奇偶性相同
```

---

### 查询 `[1,3]`

区间：

```text
[4,4,2]
```

判断：

```cpp
s[1] == s[3]
```

结果：

```text
false
```

因为：

```text
4 和 4 → 相同
4 和 2 → 相同
```

### 查询 `[3,4]`

区间：

```text
[2,5]
```

```cpp
s[3] == s[4]
```

```text
true
```

```text
2 和 5 → 奇偶性不同
```

# 6. 易错点分析

|易错点|正确做法|
|---|---|
|01数组定义方向|**奇偶相同记 1，奇偶不同记 0**|
|`s` 数组长度|本题的定义下为 `n`，不是 `n+1`|
|`s[0]`|必须初始化为 `0`|
|前缀统计含义|`s[i]` 表示 `nums[0..i]` 中出现了多少次相邻奇偶相同|
|查询区间|`queries[i] = [L,R]` 是**闭区间**|
|查询判断|`s[L] == s[R]`|
|不要直接判断两端|`nums[L]` 与 `nums[R]` 奇偶性相同/不同与整个区间是否特殊无关|
|`i` 的循环范围|构建 `s` 时 `i < n-1`，因为要访问 `nums[i+1]`|
|相邻关系数量|`n` 个元素只有 `n-1` 对相邻元素|

# 7. 复杂度分析

### 时间复杂度

构建前缀统计：

```text
O(n)
```

每个查询：

```text
O(1)
```

总共有 `q` 个查询：

```text
O(q)
```

所以总时间复杂度：

```text
O(n + q)
```

### 空间复杂度

需要额外维护：

```cpp
vector<int> s(n);
```

因此额外空间复杂度：

```text
O(n)
```

如果把返回结果 `ans` 也计算在内，则总空间为：

```text
O(n + q)
```

# 8. 核心知识点总结

这道题的本质：

```text
判断特殊数组
      ↓
判断是否存在“相邻奇偶性相同”
      ↓
把这个问题转换成 01 数组
      ↓
奇偶相同 → 1
奇偶不同 → 0
      ↓
对 01 数组进行前缀统计
      ↓
查询 [L,R]
      ↓
比较 s[L] 和 s[R]
      ↓
相等 → 中间没有新增问题 → true
不等 → 中间存在问题 → false
```

### 最重要的记忆点

> **把“区间内有没有问题”转换成“前缀统计值有没有发生变化”。**

也就是：

```cpp
s[L] == s[R]
```

等价于：

```cpp
s[R] - s[L] == 0
```

表示：

> **从 `L` 到 `R` 的过程中，没有出现相邻元素奇偶性相同。**

因此 `[L,R]` 是特殊数组。
