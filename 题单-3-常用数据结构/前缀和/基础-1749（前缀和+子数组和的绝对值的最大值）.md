> 核心思想：**前缀和 + 极差转化**——子数组和 → 前缀和之差 → 绝对值 → 数轴两点距离 → 最大值减最小值。预处理 O(n)，一次遍历 O(1)。

## 1. 题意概括

给出整数数组 `nums`，求任意子数组（**可以为空**）的**和的绝对值**的最大值。

即求：`max | nums[l] + nums[l+1] + ... + nums[r] |`，其中 `0 ≤ l ≤ r < n`，空子数组和为 `0`。

## 2. 核心思路

区间连续求和 → 用前缀和把重复计算的公共部分提前算好。

### 2.1 前缀和定义

```cpp
prefix[0] = 0;
prefix[i + 1] = prefix[i] + nums[i];   // = nums[0..i] 的和
```

长度 `n + 1`，且 `prefix[0] = 0`。

### 2.2 子数组和 → 前缀和之差

任意子数组 `nums[l..r]` 的和为：

```
sum(l, r) = prefix[r + 1] - prefix[l]
```

于是题目转化为：

```
Ans = max | prefix[j] - prefix[i] |   (0 ≤ i, j ≤ n)
```

### 2.3 几何意义：数轴距离

把 `prefix` 看作一维数轴上的点，`|prefix[j] - prefix[i]|` 就是两点间的距离。

**距离最大 ⇔ 取数值最大的点与数值最小的点**，即：

```
Ans = max(prefix) - min(prefix)
```

> 注意：这里**不关心 i 和 j 的先后顺序**。因为绝对值抹去了方向，无论最大值在最小值左边还是右边，总能截取一段合法子数组，使其绝对和等于极差。

### 2.4 空子数组与初始化

空子数组和为 `0`，对应 `prefix[0] = 0`。因此 `0` 必须参与最大值、最小值的比较。

所以初始化：

```cpp
int min_p = 0, max_p = 0;
```

遍历过程中滚动更新当前前缀和 `cur`，并维护 `min_p`、`max_p`。

## 3. 代码展示

```cpp
class Solution {
public:
    int maxAbsoluteSum(vector<int>& nums) {
        int min_p = 0, max_p = 0;   // prefix[0] = 0 必须参与比较
        int cur = 0;                 // 滚动前缀和
        for (int x : nums) {
            cur += x;
            min_p = min(min_p, cur);
            max_p = max(max_p, cur);
        }
        return max_p - min_p;
    }
};
```

> 若保留前缀和数组，则先构建 `prefix`，再对 `prefix[0..n]` 求极差，效果相同。

## 4. 易错点分析

| 易错点 | 正确做法 |
| --- | --- |
| `min_p` / `max_p` 初始化方向 | 找最小值初始为 `INT_MAX`，找最大值初始为 `INT_MIN`？**错！** 本题必须初始化为 `0`，因为 `prefix[0] = 0` 是合法候选值 |
| 忘记包含 `prefix[0] = 0` | 必须把 `0` 纳入极值比较，否则全正数数组会出错（答案偏大） |
| 混淆“最大子数组和”（Kadane） | 本题是**绝对值最大**，顺序无关，直接取全局极差即可；Kadane 需要限制 `r > l`，不能直接套用 |
| 前缀和数组长度 | 若用数组，长度应为 `n + 1`，且 `prefix[0] = 0` |
| 整数溢出 | `nums[i] ≤ 10^4`，`n ≤ 10^5`，总和最大 `10^9`，极差最大 `2×10^9`，在 `int` 范围内（约 `2.1×10^9`），可用 `int`；保险起见可用 `long long` |

## 5. 复杂度分析

- **时间 O(n)：** 只需一次遍历，滚动维护前缀和与极值。
- **空间 O(1)：** 仅用常数个变量；若保留前缀和数组则为 O(n)。

## 6. 示例

```text
nums   = {1, -3, 2, 3, -4}
前缀和 = {0, 1, -2, 0, 3, -1}
最大值 = 3，最小值 = -2
答案   = 3 - (-2) = 5
对应子数组 [2, 3]，和为 5，绝对值为 5 ✓

nums   = {2, -5, 1, -4, 3, -2}
前缀和 = {0, 2, -3, -2, -6, -3, -5}
最大值 = 2，最小值 = -6
答案   = 2 - (-6) = 8
对应子数组 [-5, 1, -4]，和为 -8，绝对值为 8 ✓
```

**笔记心得**：  
这道题的关键不是前缀和本身，而是**把“绝对值最大”抽象成“数轴距离最大”**，从而发现顺序无关，直接取极差。初始化时务必把 `prefix[0] = 0` 当作合法点，这是空子数组在数学结构上的体现。
