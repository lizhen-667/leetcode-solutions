
> 核心思想：**前缀和 + 枚举窗口 + 分段求值转换**  
> 预处理 `O(n)`，枚举 `O(n)`，总时间复杂度 `O(n)`。

---

## 1. 题意概括

给定数组 `prices` 和 `strategy`，以及偶数 `k`。

- `prices[i]`：第 `i` 天股票价格
- `strategy[i]`：`-1` 买入，`0` 持有，`1` 卖出
- 利润 = `Σ strategy[i] * prices[i]`

可以 **最多一次** 修改：

- 选择恰好 `k` 个连续元素
- 前 `k/2` 个设为 `0`（持有）
- 后 `k/2` 个设为 `1`（卖出）

求修改后能获得的最大利润。

---

## 2. 核心思路

直接枚举所有长度为 `k` 的窗口，计算修改后的利润，取最大值。

但每次重新计算窗口内利润太慢，因此使用 **前缀和**：

- `prefix[i]`：前 `i` 天原始利润和  
  `prefix[i] = Σ prices[j] * strategy[j], j ∈ [0, i)`
- `prices_sum[i]`：前 `i` 天价格和  
  `prices_sum[i] = Σ prices[j], j ∈ [0, i)`

答案初始为不修改的利润：`ans = prefix[n]`。

---

## 2.1 前缀和数组构建

```cpp
vector<long long> prefix(n + 1, 0);      // 原始利润前缀和
vector<long long> prices_sum(n + 1, 0);  // 价格前缀和

for (int i = 0; i < n; i++) {
    prefix[i + 1] = prefix[i] + (long long)prices[i] * strategy[i];
    prices_sum[i + 1] = prices_sum[i] + prices[i];
}
```

> `prices_sum` 必须用 `long long`，因为最大可达 `10^10`。

---

## 2.2 分段求值转换

设修改窗口为 `[L, R]`，长度为 `k`，即 `R = L + k - 1`。

为了配合前缀和，令 `i = R + 1 = L + k`，则：

- 窗口为 `[i - k, i - 1]`
- 窗口前半段：`[i - k, i - k/2)`，修改后全为 `0`，贡献为 `0`
- 窗口后半段：`[i - k/2, i)`，修改后全为 `1`，贡献为这些天的价格和

整段利润分为三部分：

1. **窗口左边** `[0, i - k)`：保持原样 → `prefix[i - k]`
2. **窗口内后半段** `[i - k/2, i)`：变为 `1` → `prices_sum[i] - prices_sum[i - k/2]`
3. **窗口右边** `[i, n)`：保持原样 → `prefix[n] - prefix[i]`

合并得：

```text
t = prefix[i - k] + prefix[n] - prefix[i]
    + prices_sum[i] - prices_sum[i - k/2]
```

---

## 3. 枚举窗口

```cpp
long long ans = prefix[n];  // 不修改的情况

for (int i = k; i <= n; i++) {
    long long t = prefix[i - k] + prefix[n] - prefix[i]
                + prices_sum[i] - prices_sum[i - k/2];
    ans = max(ans, t);
}
```

- `i` 表示窗口右端点的下一个位置，窗口为 `[i - k, i - 1]`
- 循环条件 `i <= n`，确保包含最后一个窗口 `[n - k, n - 1]`

---

## 3.1 为什么 `i` 从 `k` 到 `n`？

- 当 `i = k` 时，窗口为 `[0, k - 1]`，是最左边的窗口。
- 当 `i = n` 时，窗口为 `[n - k, n - 1]`，是最右边的窗口。
- 若写成 `i < n`，会漏掉最后一个窗口，导致答案错误。

---

## 3.2 公式推导要点

- 窗口内前半段变成 `0`，对利润贡献为 `0`，所以不用计算原策略。
- 窗口内后半段变成 `1`，贡献等于这些天的价格和，即：
  ```text
  prices_sum[i] - prices_sum[i - k/2]
  ```
- 窗口外部分保持原策略，直接用前缀和相减。

---

## 4. 代码展示

```cpp
class Solution {
public:
    long long maxProfit(vector<int>& prices, vector<int>& strategy, int k) {
        int n = prices.size();

        vector<long long> prefix(n + 1, 0);
        vector<long long> prices_sum(n + 1, 0);

        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + (long long)prices[i] * strategy[i];
            prices_sum[i + 1] = prices_sum[i] + prices[i];
        }

        long long ans = prefix[n];  // 不修改

        for (int i = k; i <= n; i++) {
            long long t = prefix[i - k] + prefix[n] - prefix[i]
                        + prices_sum[i] - prices_sum[i - k / 2];
            ans = max(ans, t);
        }

        return ans;
    }
};
```

## 5. 示例

```text
prices = [4, 2, 8]
strategy = [-1, 0, 1]
k = 2
```

原始利润：

```text
(-1×4) + (0×2) + (1×8) = 4
```

前缀和：

```text
prefix:      [0, -4, -4, 4]
prices_sum:  [0,  4,  6, 14]
```

枚举窗口：

- `i = 2`，窗口 `[0, 1]`  
  `t = prefix[0] + prefix[3] - prefix[2] + prices_sum[2] - prices_sum[1]`  
  `= 0 + 4 - (-4) + 6 - 4 = 10`
- `i = 3`，窗口 `[1, 2]`  
  `t = prefix[1] + prefix[3] - prefix[3] + prices_sum[3] - prices_sum[2]`  
  `= -4 + 4 - 4 + 14 - 6 = 4`

最大利润 `max(4, 10, 4) = 10`。

---

## 6. 易错点分析

| 易错点 | 正确做法 |
|---|---|
| `prices_sum` 使用 `int` | 必须用 `long long`，防止溢出 |
| 循环范围写成 `i < n` | 应为 `i <= n`，否则漏掉最后一个窗口 |
| 窗口内后半段区间计算错误 | 后半段是 `[i - k/2, i)`，价格和为 `prices_sum[i] - prices_sum[i - k/2]` |
| 忘记初始化 `ans = prefix[n]` | 表示“不修改”的情况，防止修改后利润更低 |
| 窗口左端点计算 | `i` 是右端点下一个位置，窗口为 `[i-k, i-1]` |
| 乘法溢出 | `prices[i] * strategy[i]` 虽然值不大，但规范应转 `long long` |
| `k/2` 的整除 | `k` 是偶数，`k/2` 为整数，直接使用 |

## 7. 复杂度分析

### 时间复杂度

- 构建前缀和：`O(n)`
- 枚举窗口：`O(n)`
- 总时间复杂度：`O(n)`

### 空间复杂度

- 两个前缀和数组：`O(n)`
- 总空间复杂度：`O(n)`

## 8. 核心知识点总结

```text
求最大利润
    ↓
基础利润 = Σ prices[i] * strategy[i]
    ↓
枚举所有长度为 k 的窗口
    ↓
用前缀和 O(1) 计算修改后利润
    ↓
利润分三段：
    左段：prefix[i-k]
    中段后半：prices_sum[i] - prices_sum[i-k/2]
    右段：prefix[n] - prefix[i]
    ↓
取 max(基础利润, 所有修改后利润)
```

### 最重要的记忆点

> **窗口内前半段变 0 不用算，后半段变 1 只取价格和；窗口外保持原样用前缀和。**

即：

```cpp
t = prefix[i-k] + prefix[n] - prefix[i]
    + prices_sum[i] - prices_sum[i-k/2];
```

循环 `i` 从 `k` 到 `n`，答案初始为 `prefix[n]`。
