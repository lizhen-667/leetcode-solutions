> 核心思想：**前缀和 + 枚举右端点 + 维护历史最小前缀和**——子数组和 → 前缀和之差 → 固定右端点，让左前缀和尽可能小 → 最大差值。预处理 O(n)，一次遍历 O(1)。

## 1. 题意概括

给出整数数组 `nums`，求**非空连续子数组**的最大和。

即求：`max ( nums[l] + nums[l+1] + ... + nums[r] )`，其中 `0 ≤ l ≤ r < n`。

> 注意：子数组必须非空，所以全负数数组的答案也是负数，不能默认返回 0。

## 2. 核心思路

区间连续求和 → 用前缀和把重复计算的公共部分提前算好。

### 2.1 前缀和定义

```cpp
prefix[0] = 0;
prefix[i + 1] = prefix[i] + nums[i];   // = nums[0..i] 的和
```

长度 `n + 1`，且 `prefix[0] = 0`。

### 2.2 子数组和 → 前缀和之差

任意子数组 `nums[l..r]` 的和为：

```text
sum(l, r) = prefix[r + 1] - prefix[l]
```

令右端点前缀和为 `pre_sum`，左端点前缀和为 `min_pre_sum`，则：

```text
以 nums[i] 结尾的最大子数组和 = pre_sum - min_pre_sum
```

其中 `min_pre_sum` 必须是 `i` 之前出现过的最小前缀和。

### 2.3 枚举右端点 + 维护历史最小值

遍历数组，滚动维护：

- `pre_sum`：当前前缀和（枚举右端点）
- `min_pre_sum`：从开始到当前元素之前的最小前缀和
- `ans`：全局最大子数组和

每步更新：

```cpp
ans = max(ans, pre_sum - min_pre_sum);
min_pre_sum = min(min_pre_sum, pre_sum);
```

**顺序不能反**：必须先算 `ans`，再更新 `min_pre_sum`。否则会变成当前前缀和自己减自己，得到 0，相当于允许空子数组，全负数数组会出错。

### 2.4 与 121 题（买卖股票）的类比

| 题目 | 枚举的是什么 | 维护的历史最值 | 更新答案 |
| --- | --- | --- | --- |
| 121 买卖股票 | 枚举卖出日 `i` | 历史最低买入价 `pre_min` | `ans = max(ans, prices[i] - pre_min)` |
| 53 最大子数组和 | 枚举右端点 `i` | 历史最小前缀和 `min_pre_sum` | `ans = max(ans, pre_sum - min_pre_sum)` |

两者结构完全一致：

```text
遍历 → 更新当前量 → 用当前量减去历史最值更新答案 → 更新历史最值
```

这就是「枚举 + 维护历史最优」这一类题的通法。

### 2.5 与 Kadane 算法的等价性

Kadane 算法：

```cpp
cur = max(nums[i], cur + nums[i]);
ans = max(ans, cur);
```

其中 `cur` 表示「以当前元素结尾的最大子数组和」。

而前缀和写法中的：

```cpp
pre_sum - min_pre_sum
```

其实就等于 Kadane 里的 `cur`。两者完全等价：

- 前缀和视角：`cur = pre_sum - min_pre_sum`
- Kadane 视角：`cur = max(nums[i], cur + nums[i])`

Kadane 更直观，前缀和写法更强调「枚举 + 维护历史最小值」。

## 3. 代码展示

### 3.1 前缀和写法（推荐理解枚举思想）

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int ans = INT_MIN;          // 子数组非空，不能初始化为 0
        int min_pre_sum = 0;        // 虚拟前缀和 prefix[0] = 0
        int pre_sum = 0;            // 滚动前缀和

        for (int x : nums) {
            pre_sum += x;                           // 当前前缀和
            ans = max(ans, pre_sum - min_pre_sum);  // 先更新答案
            min_pre_sum = min(min_pre_sum, pre_sum);// 再更新历史最小前缀和
        }
        return ans;
    }
};
```

### 3.2 Kadane 写法（更简洁）

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int ans = nums[0];
        int cur = nums[0];

        for (int i = 1; i < nums.size(); i++) {
            cur = max(nums[i], cur + nums[i]);
            ans = max(ans, cur);
        }
        return ans;
    }
};
```

## 4. 易错点分析

| 易错点 | 正确做法 |
| --- | --- |
| `ans` 初始化为 0 | **错！** 子数组必须非空，全负数时答案也是负数。应初始化为 `INT_MIN` 或 `nums[0]` |
| `min_pre_sum` 初始化为 `INT_MAX` | **错！** 必须初始化为 `0`，因为 `prefix[0] = 0` 是合法候选值，对应子数组从下标 0 开始的情况 |
| 先更新 `min_pre_sum` 再算 `ans` | **错！** 必须先算 `ans` 再更新，否则相当于允许空子数组，全负数会返回 0 |
| 混淆「最大子数组和」与「最大绝对值和」 | 本题要求 `i > j`，顺序重要，不能直接取极差；最大绝对值和那题顺序无关，取 `max(prefix) - min(prefix)` |
| 忘记 `min_pre_sum` 的物理意义 | 它代表「在右端点之前出现过的最小前缀和」，不是当前前缀和 |
| 整数溢出 | `nums[i] ≤ 10^4`，`n ≤ 10^5`，总和最大 `10^9`，在 `int` 范围内（约 `2.1×10^9`），可用 `int`；保险起见可用 `long long` |

## 5. 复杂度分析

- **时间 O(n)：** 只需一次遍历，滚动维护前缀和与历史最小值。
- **空间 O(1)：** 仅用常数个变量；若保留前缀和数组则为 O(n)。

## 6. 示例

```text
nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]

过程：
i    nums[i]   pre_sum   min_pre_sum   pre_sum - min_pre_sum   ans
0    -2        -2        0             -2                      -2
1     1        -1       -2              1                       1
2    -3        -4       -2             -2                       1
3     4         0       -4              4                       4
4    -1        -1       -4              3                       4
5     2         1       -4              5                       5
6     1         2       -4              6                       6
7    -5        -3       -4              1                       6
8     4         1       -4              5                       6

答案 = 6
对应子数组 [4, -1, 2, 1]，和为 6 ✓
```

---

**笔记心得**：  
这道题的关键是**把「连续子数组和最大」转化为「枚举右端点，维护左端点最小前缀和」**。它与 121 题买卖股票的结构完全一致，都是「枚举 + 维护历史最值」的模板。务必注意三个细节：

1. `ans` 初始化为 `INT_MIN`，因为子数组非空；
2. `min_pre_sum` 初始化为 `0`，因为 `prefix[0] = 0` 是合法起点；
3. 先更新 `ans`，再更新 `min_pre_sum`，否则会允许空子数组，全负数出错。

理解了前缀和视角，也就理解了 Kadane 算法——两者本质相同，只是观察角度不同。
