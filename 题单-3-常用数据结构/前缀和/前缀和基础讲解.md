# 前缀和基础讲解

> 核心思想:**预处理 O(n),区间和查询 O(1)**

## 1. 定义

`s[i]` = 前 i 个数的和 = `nums[0] + nums[1] + ... + nums[i-1]`

- 前缀和数组长度:`s.resize(nums.size() + 1)`,共 `n + 1` 个元素
- `s[0] = 0`(前 0 个数的和),作为公式基准

## 2. 构建(O(n))

```cpp
vector<int> s(nums.size() + 1, 0);   // 初始全 0,s[0] 自动为 0
for (int i = 0; i < nums.size(); i++) {
    s[i + 1] = s[i] + nums[i];
}
```

## 3. ★ 核心公式:区间和查询(O(1))

**`nums[l] ~ nums[r]` 的和 = `s[r + 1] - s[l]`**

```cpp
int sum = s[r + 1] - s[l];   // 闭区间 [l, r],下标从 0 开始
```

> 记忆口诀:**右端点 +1 减左端点**

## 4. 易错点

| 易错点 | 正确做法 |
| --- | --- |
| 数组长度 | 前缀和长度是 `n + 1`,不是 `n` |
| 下标偏移 | 区间和用 `s[r+1] - s[l]`,不是 `s[r] - s[l-1]` |
| 忘记 `s[0] = 0` | 保证 `l = 0` 时公式成立 |
| 溢出 | 数据范围大时改用 `long long` |

## 5. 边界情况

- `l = 0`:`sum = s[r + 1] - s[0]`,因 `s[0] = 0` 正常成立
- `l = r`:单个元素 `nums[l] = s[l+1] - s[l]`
- 空数组:前缀和数组长度 1(仅 `s[0]`),构建循环不执行
- 全负数 / 全零:公式不受影响

## 6. 示例

```text
nums = {1, 3, 5, 7, 9}
s    = {0, 1, 4, 9, 16, 25}

求 nums[1..3] 的和 = 3 + 5 + 7 = 15
s[4] - s[1] = 16 - 1 = 15 ✓
```
