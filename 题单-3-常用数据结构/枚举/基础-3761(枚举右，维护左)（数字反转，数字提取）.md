**题意：**

给定一个整数数组 `nums`，定义「镜像对」为满足以下两个条件的下标对 `(i, j)`：

1. `0 <= i < j < nums.length`（i 在前，j 在后）；
2. `reverse(nums[i]) == nums[j]`，其中 `reverse(x)` 是把整数 x 的各位数字倒过来形成的数，且忽略前导零（如 `reverse(120) = 21`）。

要求：返回所有镜像对中 `abs(i - j)` 的最小值；若不存在任何镜像对，返回 `-1`。

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

**核心思路：**

- 题型模式：枚举右，维护左（哈希表）
- 方向固定：只判断「前面某个数的反转 == 当前数」，即 `reverse(nums[i]) == nums[j]`，反过来的 `reverse(nums[j]) == nums[i]` 不成立
- 枚举右端点 `j`：先查哈希表中是否有 key = `nums[j]`，有则说明存在左端点 `i` 满足 `reverse(nums[i]) == nums[j]`，用 `j - i` 更新答案
- 再计算 `res = reverse(nums[j])`，把 `res -> j` 写入哈希表，作为后续右端点可用的左端点
- 哈希表存「最近一次出现的下标」：同一个 key 对应多个左端点时，越靠右的 i 与将来的 j 距离越小，所以每次直接覆盖为 j 即可
- 数字反转去前导零：`res = res * 10 + x % 10; x /= 10;` 逐位提取累加，120 → 21、1000 → 1，天然忽略前导零

**代码：**

```cpp
class Solution {
public:
    int reverseNum(int x) {  // 反转数字，忽略前导零
        int res = 0;
        while (x > 0) {
            res = res * 10 + x % 10;
            x /= 10;
        }
        return res;
    }

    int minMirrorPairDistance(vector<int>& nums) {
        unordered_map<int, int> last;  // 反转值 -> 该值最近一次出现的下标
        int ans = INT_MAX;

        for (int j = 0; j < (int)nums.size(); ++j) {
            // 先查：前面是否存在 nums[i] 满足 reverse(nums[i]) == nums[j]
            auto it = last.find(nums[j]);
            if (it != last.end()) {
                ans = min(ans, j - it->second);
            }
            // 后更新：把当前数的反转值记为候选左端点
            last[reverseNum(nums[j])] = j;
        }
        return ans == INT_MAX ? -1 : ans;
    }
};
```

**复杂度：**

- 时间：O(n * d)，d 为数字位数（nums[i] <= 10^9，d <= 10），即 O(n)
- 空间：O(n)，哈希表最多存 n 个键值对

**踩坑/细节：**

- 必须「先查后更新」：若先把 `last[reverse(nums[j])] = j` 再查，遇到反转等于自身的数（如 11、121）时，会查到刚写入的自己，得到错误的距离 0
- 前导零：120 的反转是 21 而不是 021，用取模累加天然处理，不需要转字符串去前导零
- 方向性：`[21, 120]` 返回 -1，因为 `reverse(21) = 12 != 120`，镜像对只要求「左的反转 == 右」
- 重复值：如 `[12, 21, 12, 21]`，只保留最新下标不会漏解，因为对每个右端点 j 只需最近的那个左端点就能得到最小距离
- 无镜像对时返回 -1：用 `INT_MAX` 作哨兵，遍历结束后判断是否被更新
- 距离与下标用 int 即可（n <= 10^5），不需要 long long

**方法提炼：**

- 「枚举右，维护左」模板：遍历到 j 时左边信息已在哈希表中，先查后更，每个数 O(1) 完成一次配对
- 求「最小距离」时，哈希表存「最近一次出现的下标」而不是「第一次出现的下标」，保证同一个右端点取到最优左端点
- 数字反转/数字提取模板：`res = res * 10 + x % 10; x /= 10;`，整数逐位处理的标准写法
