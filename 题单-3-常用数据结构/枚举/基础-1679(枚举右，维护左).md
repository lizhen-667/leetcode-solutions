题意：
**给你一个整数数组 `nums` 和一个整数 `k` 。**
**每一步操作中，你需要从数组中选出和为 `k` 的两个整数，并将它们移出数组。**
**返回你可以对数组执行的最大操作数。**

易错点：
**对于该题是典型的枚举右，维护左问题，对于此类问题一般是先检查，再插入。而如果先插入，再检查的话，导致元素可能和自己配对，这就不符合题目要求，导致产生bug。**

错误代码：
```cpp
int maxOperations(vector<int>& nums, int k) {
        unordered_map<int,int> umap;
        int target=0;
        int ans=0;
        for(int i=0;i<nums.size();i++){
            int target=k-nums[i];
            umap[nums[i]]++;
            if(umap[target]>0){
                umap[target]--;
                ans++;
                umap[nums[i]]--;
            }
        }
        return ans;
    }
```

正确代码：
```cpp
int maxOperations(vector<int>& nums, int k) {
        unordered_map<int,int> umap;
        int target=0;
        int ans=0;
        for(int i=0;i<nums.size();i++){
            int target=k-nums[i];
           
            if(umap[target]>0){
                umap[target]--;
                ans++;
                continue;
            }
            umap[nums[i]]++;
        }
        return ans;
    }
```
