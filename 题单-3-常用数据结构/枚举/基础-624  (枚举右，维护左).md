给定m个数组都已按照升序排好序  从两个不同的数组中选择两个整数 并且计算它们的距离 两个整数ab之间的距离定义为它们差的绝对值|a-b|

==我最初的思路：==
*找全局最大值->在不同的数组中找最小值->返回差值*
 
==仅仅计算这一种情况 输出错误==：
*漏掉了对称的另一种情况：全局最小值和来自不同数组的最大值配对*

*当全局最大值和最小值恰好落在同一个数组中时，两种情况的答案不同，我的代码会得到错误的结果*

`class Solution {`
  `public:`
      `int maxDistance(vector<vector<int>>& arrays) {`
          `int n = arrays.size();`

          `// 找全局最大值及其所在数组`
          `int globalMax = arrays[0].back(), maxIdx = 0;`
          `// 找全局最小值及其所在数组`
          `int globalMin = arrays[0][0], minIdx = 0;`

          `for (int i = 1; i < n; i++) {`
              `if (arrays[i].back() > globalMax) {`
                  `globalMax = arrays[i].back();`
                  `maxIdx = i;`
              `}`
              `if (arrays[i][0] < globalMin) {`
                  `globalMin = arrays[i][0];`
                  `minIdx = i;`
              `}`
          `}`

          `// 情况 A：全局最大值 配 忽略maxIdx后的最小值`
          `// 情况 B：全局最小值 配 忽略minIdx后的最大值`
          `int ans = 0;`
          `for (int i = 0; i < n; i++) {`
              `if (i != maxIdx) {`
                  `ans = max(ans, globalMax - arrays[i][0]);`
              `}`
              `if (i != minIdx) {`
                  `ans = max(ans, arrays[i].back() - globalMin);`
              `}`
          `}`

          `return ans;`
      `}`
  `};`
