题意：
给定一个 `m × n` 的 **0/1 矩阵** `grid`：

- 矩阵中的 **1** 视为可选的点（顶点），0 不可用；
- 要求选出 **3 个值为 1 的格子** 组成一个直角三角形；
- 三角形的两条**直角边必须平行于矩阵的行或列**（即与坐标轴对齐，不能是斜的）。

**求：满足条件的直角三角形一共有多少个？**

约束：`1 ≤ m, n ≤ 1000`，答案可能很大，用 `long long` 返回。

解题思路：

- 题型模式：枚举中间（直角顶点）+ 行列计数统计
- 每个直角三角形有且仅有一个直角顶点，且两条直角边分别平行于行、列
- 若格子 `(i, j) = 1` 作为直角顶点：
  - 另一条边上的顶点必须是**同一行**里的另一个 1：`行内 1 的个数 - 1` 种选法（减掉自己）
  - 另一条边上的顶点必须是**同一列**里的另一个 1：`列内 1 的个数 - 1` 种选法
  - 两个选择相互独立 → 该格贡献 = `(行内 1 的个数 - 1) × (列内 1 的个数 - 1)`
- 按直角顶点归类统计**不重不漏**（每个三角形只有一个直角顶点），答案 = 对所有为 1 的格子求和上述乘积
- 把"同时找同行同列两个点"拆成"行列计数各算一个"，避免 O(m²n²) 暴力枚举

代码：

```cpp
class Solution {
public:
    long long numberOfRightTriangles(vector<vector<int>>& grid) {
        int n = grid[0].size();                 // 列数
        vector<int> col_sum(n, -1);             // 提前减一：col_sum[j] = 第 j 列 1 的个数 - 1
        for (auto& row : grid) {
            for (int j = 0; j < n; j++) {
                col_sum[j] += row[j];
            }
        }

        long long ans = 0;
        for (auto& row : grid) {
            int row_sum = reduce(row.begin(), row.end()) - 1; // 提前减一：行内 1 的个数 - 1
            for (int j = 0; j < row.size(); j++) {
                if (row[j] == 1) {
                    ans += row_sum * col_sum[j]; // 当前格作为直角顶点的贡献
                }
            }
        }
        return ans;
    }
};
```

语义更直白的等价写法（不减一前移，在乘式里减）：

```cpp
class Solution {
public:
    long long numberOfRightTriangles(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        vector<int> col(n, 0);
        for (auto& row : grid)
            for (int j = 0; j < n; j++)
                col[j] += row[j];               // 第 j 列 1 的个数

        long long ans = 0;
        for (auto& row : grid) {
            int rowOnes = accumulate(row.begin(), row.end(), 0); // 行内 1 的个数
            for (int j = 0; j < n; j++)
                if (row[j] == 1)
                    ans += 1LL * (rowOnes - 1) * (col[j] - 1);
        }
        return ans;
    }
};
```

复杂度：
O(m·n) 时间（预处理列和 + 逐行扫描各一遍）/ O(n) 空间（只存一个列和数组）

注意点：
- 行数、列数的获取：`int row = grid.size();`、`int col = grid[0].size();`（详见《二维数组获取行数和列数》）
- 对某一行求和：`reduce(row.begin(), row.end())`，参数是**该行的迭代器**（不是 `grid.begin()`）；`[begin, end)` 左开右闭区间，需要 C++17 与 `<numeric>`
- 更通用的写法：`accumulate(row.begin(), row.end(), 0)`，C++98 就有，注意要传第三个初值参数 0
- `reduce`/`accumulate` 的返回类型：`vector<int>` 时是 `int`，行列很大时求和可能溢出，注意数据范围
- 乘法防溢出：`row_sum * col_sum[j]` 是两个 int 相乘，m、n ≤ 1000 时乘积 ≤ 10⁶ 没问题；数据更大时应写成 `1LL * row_sum * col_sum[j]`
- 答案必须用 `long long` 累加：极端全 1 矩阵时可达约 10¹² 量级，int 装不下
- 行或列全 0 时对应计数为 -1，但 `row[j] == 1` 不成立不会进入累加，不会产生负贡献
- `for (auto& row : grid)` 用引用遍历，避免复制整行（性能更好）

方法提炼：
- "枚举中间"题型：固定中间元素（本题为直角顶点），贡献 = 两个方向上可选个数之积，方向间相互独立即可拆分计数
- 先用一遍扫描预处理列统计，再第二遍扫描边算边用，把 O(m²n²) 暴力降到 O(mn)
- 计数题先想"以谁为锚点统计不重不漏"：每个三角形只有一个直角顶点，锚在直角顶点上
- 提前减一（-1 初始化）让主循环直接复用现成计数，是常见的小优化，注意与语义对应
