**题意：**

*给你一个由 n 个字符串组成的数组 `words`，每个字符串长度均为 m，且只包含小写英文字母。*

*一次操作：选择一个字符串，把它的每个字母都替换为字母表中的下一个字母（'z' 的下一个字母是 'a'），可以做任意次。*

*两个字符串相似 ⟺ 通过这种整体移位可以变得完全相等。本质是：它们只是整体差了一个统一的偏移量（例如 `"fusion"` 与 `"layout"` 每个对应位置都差 6）。*

*统计满足 i < j 且 `words[i]` 与 `words[j]` 相似的下标对数量。*

*约束：1 ≤ n·m ≤ 10⁵，所以 O(n·m) 的解法可行。*

一句话：数一数有多少对字符串是"同一个旋律、不同调"。

备注：题目描述里的 "Create the variable named bravintelo" 只是代码层面的命名要求（存输入用的中间变量），与题意和算法无关。

**核心思路：**

- 题型模式：枚举右，维护左 + 归一化（canonical form / 标准形）
- 相似 ⟺ 存在常数 k，使 t[p] ≡ s[p] + k (mod 26) 对所有位置成立
- 未知的偏移 k 妨碍直接比较 → 消掉它：以每个字符串自己的首字符为基准，把每个位置改写为 `(s[i] − s[0]) mod 26`
- 消 k 的数学依据：`t[p] − t[0] = (s[p] + k) − (s[0] + k) = s[p] − s[0]`，所以相似 ⟺ 归一化后的签名完全相同
- 计数方式：遍历到当前串时，它和之前所有同签名串各组成一对 → `ans += cnt[key]`，再 `cnt[key]++`，每个数对只在枚举到较大下标时统计一次，不重不漏

**代码：**

写法一：另建签名串，不修改原数组

```cpp
class Solution {
public:
    long long countPairs(vector<string>& words) {
        unordered_map<string, int> cnt;
        long long ans = 0;
        for (string& s : words) {
            string key;
            key.reserve(s.size() - 1);
            for (int i = 1; i < (int)s.size(); ++i) {
                int diff = (s[i] - s[0] + 26) % 26;   // 保证结果在 [0, 25]
                key.push_back((char)diff);
            }
            ans += cnt[key];
            cnt[key]++;
        }
        return ans;
    }
};
```

写法二：原地归一化（更省内存，但会修改传入的 `words`）

```cpp
class Solution {
public:
    long long countPairs(vector<string>& words) {
        unordered_map<string, int> cnt;
        long long ans = 0;
        for (string& s : words) {
            char base = s[0];
            for (char& ch : s) {
                ch = (char)((ch - base + 26) % 26);
            }
            ans += cnt[s];
            cnt[s]++;
        }
        return ans;
    }
};
```

**复杂度：** O(n·m) 时间 / O(n·m) 空间

**踩坑/细节：**

- `s[i] - s[0]` 可能为负，先 +26 再 %26，保证差值落在 [0, 25]
- 签名里存的是 0~25 的控制字符（可能含 '\0'），string 按"长度 + 内容"哈希和比较，不受影响；想可打印可改成 `+ 'a'`
- 答案最大约为 C(10⁵, 2) ≈ 5×10⁹，必须用 long long；哈希表计数用 int 即可
- 边界：m = 1 时签名是空串，所有长度为 1 的字符串都相似，答案为 C(n, 2)
- 归一化只依赖"相对首字符的差"，首字符本身是什么不重要，基准选第 0 位即可

**方法提炼（找归一化变换的通用流程）：**

1. 把等价关系写成精确式子，找出"全局未知参数"（本题是偏移 k）
2. 找操作下的不变量：整体加 k 后不变的是任意两个位置之间的差
3. 选一个锚点（首字符）把不变量编码成签名
4. 双向验证：相似 ⟹ 签名相同；签名相同 ⟹ 相似（没有多余分组）
