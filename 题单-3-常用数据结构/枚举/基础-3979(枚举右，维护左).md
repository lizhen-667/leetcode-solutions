题意：
***给你一个长度为 `n` 的整数数组 `nums` 和一个整数 `k` 。***
***如果满足以下条件，则下标对 `(i, j)` 被称为 有效 的：***

- ***`0 <= i < j < n`***
- ***`j - i >= k`***

***返回所有有效对中的 `nums[i] + nums[j]` 的 最大 值。***

思路:
***对于每个右端点 j，我们需要在 [0, j-k] 范围内找到最大的 nums[i]。***

核心逻辑:

***遍历 j 从 k 到 n-1，同时维护 maxLeft = max(nums[0 .. j-k])：***

***j = k 时，候选 i 只有 0        → maxLeft = nums[0]***
***j = k+1 时，候选 i 有 0, 1     → maxLeft = max(maxLeft, nums[1])***
***j = k+2 时，候选 i 有 0, 1, 2  → maxLeft = max(maxLeft, nums[2])  ...***

***每一步用 maxLeft + nums[j] 更新答案即可。***

代码:
 ***int maxValidPairSum(vector<int>& nums, int k) {***
 
            ***int n=nums.size();***

            ***int maxr=0;***

            ***int ans=0;***

            ***for(int j=k;j<n;j++){***

                ***int r=j-k;***

                ***maxr=max(maxr,nums[r]);***

                ***ans=max(ans,nums[j]+maxr);***

            ***}***

            ***return ans;***

    ***}***
