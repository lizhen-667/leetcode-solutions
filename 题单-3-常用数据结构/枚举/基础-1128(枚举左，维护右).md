题意：
**给你一组多米诺骨牌 `dominoes` 。**

**形式上，`dominoes[i] = [a, b]` 与 `dominoes[j] = [c, d]` 等价 当且仅当 (`a == c` 且 `b == d`) 或者 (`a == d` 且 `b == c`) 。即一张骨牌可以通过旋转 `0` 度或 `180` 度得到另一张多米诺骨牌。**

**在 `0 <= i < j < dominoes.length` 的前提下，找出满足 `dominoes[i]` 和 `dominoes[j]` 等价的骨牌对 `(i, j)` 的数量。**

错误点：
**在做这道题目时，我本能的只考虑到了常规输入，而没有刻意去验证极端条件的输入，该代码是否能得到正确的输出**
**在等价多米诺骨牌的题意下：**
  - **[1,2] 和 [2,1] 等价 → 涉及两个不同的值**
  - **[1,1] 只和另一个 [1,1] 等价 → 只涉及一个值**

  **你的算法设计本身隐含了 a 和 b**
  **是两个不同东西的假设。这不是语言语法问题，而是你没有把"自己和自己等价"当作一个独立的**
  **case 来审视。很多算法题的边界 bug 都源于这类设计假设没有显式化。**

最后写出的代码可以有两种思路：
1.区分 a==b 的情况

```cpp
int numEquivDominoPairs(vector<vector<int>>& dominoes) {
        
        int arr[10][10]={};
        int count=0;
        for(int i=0;i<dominoes.size();i++){
            int a=dominoes[i][0];
            int b=dominoes[i][1];
            count+=arr[a][b];
            arr[a][b]++;
            if(a!=b){
                arr[b][a]++;
            }
    
        }

            return count;
            
    }
```

2.统一进行处理，统一处理——只用 arr[a][b] 计数，用 min(a,b)作为第一维、max(a,b) 作为第二维来归一化存储

```cpp
int numEquivDominoPairs(vector<vector<int>>& dominoes) {
        int arr[10][10]={};
        int ans=0;
        for(int i=0;i<dominoes.size();i++){
            int a=dominoes[i][0],b=dominoes[i][1];
            int x=min(a,b),y=max(a,b);
            ans+=arr[x][y];
            arr[x][y]++;
        }
        return ans;


    }
```
