求股票的最大利润，买入日期必须在卖出日期之前
从左到右枚举卖出价格 
买入价格：买入日期必须在卖出日期之前，所以我们求的是从prices[0]到prices[i-1]的最小值，这可以用一个变量minPrice维护
在遍历中，计算prices[i]-minPrice的最大值，就是答案

int maxProfit(vector<int>& prices) {

        int ans=0;

        int min_price=prices[0];

        for(int i=1;i<prices.size();i++){

            int p=prices[i];

            ans=max(ans,p-min_price);

            min_price=min(min_price,p);

        }

        return ans;

    }

==***核心思路是一次遍历，边走边记：***==

  int min_price = prices[0];   // 遍历过程中遇到的最低价格
  int ans = 0;                  // 当前能获得的最大利润

  遍历每一天的价格 p，做两件事：

  1. ans = max(ans, p - min_price);

  算：如果我在"历史最低价那天"买入、在"今天"卖出，利润是多少？和之前的最大利润比较，取更大的。

  2. min_price = min(min_price, p);

  记：今天的价格是不是比之前见过的都低？如果是，更新最低买入价，供后面的天数使用。
