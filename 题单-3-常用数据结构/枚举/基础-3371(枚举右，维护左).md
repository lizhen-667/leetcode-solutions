**题意：**

给你一个整数数组 nums，其中恰好有 n-2 个元素是特殊数字；剩下两个元素，一个是所有特殊数字的和，另一个是异常值（既不是原始特殊数字之一，也不是表示元素和的那个数）。

**注意：**特殊数字、和以及异常值的下标必须不同，但可以共享相同的值。

**提示：**
- `3 <= nums.length <= 105`
- `-1000 <= nums[i] <= 1000`
- 输入保证 nums 中至少存在一个可能的异常值

**核心思路：**

- 题型模式：枚举候选 + 频次统计（unordered_map）
- 把数组拆成三部分：n-2 个特殊数字（和为 S）、和元素（值也是 S）、异常值 x
- 总量等式：T = S + S + x = 2S + x
- 枚举每个 x 当异常值：先 `cnt[x]--` 把它"拿走"，剩下 n-1 个数恰好是两份 S，所以 S = (T - x) / 2
- 合法性只需检查两点：T - x 是偶数；S 仍存在于数组中（若 S == x，说明原数组里 x 至少出现 2 次，正好满足"下标必须不同"）
- 剩下的 n-2 个数自动满足"和为 S"：它们的和 = T - x - S = S，无需额外验证；题目允许特殊数字与 S、x 共享相同的值
- 取所有合法 x 的最大值

**代码：**

```cpp
class Solution {
public:
    int getLargestOutlier(vector<int>& nums) {
        unordered_map<int, int> cnt;
        int total = 0;
        for (int x : nums) {
            cnt[x]++;
            total += x;
        }

        int ans = -1001;  // 小于值域下限 [-1000, 1000]，表示"尚未找到"
        for (int x : nums) {
            cnt[x]--;  // 先拿走一个 x，把它当作异常值
            // 剩余元素 = 特殊数字之和 S + 和元素 S = 2S，所以 S = (total - x) / 2
            if ((total - x) % 2 == 0 && cnt[(total - x) / 2] > 0) {
                ans = max(ans, x);
            }
            cnt[x]++;  // 还原，继续枚举下一个候选
        }
        return ans;
    }
};
```

**复杂度：** O(n) 时间 / O(n) 空间

**踩坑/细节：**
- 忘记判断 (T - x) 的奇偶性，可能把不存在的 S 当成合法候选
- "下标必须不同"：S == x 时原数组需要至少 2 个 x，代码里先 `cnt[x]--` 再查 `cnt[S]` 天然处理了这一点
- 异常值不一定是最大值（示例 2 中 -6 也合法，但答案是 4），必须扫完所有候选取 max
- 值域只有 [-1000, 1000]，也可以换成长度 2001 的定长数组计数，空间降为 O(1)
- ans 初始值用 -1001（小于值域下限），保证至少存在一个合法答案时能被正确更新

**方法提炼：**

- 三分类问题（特殊集 + 和 + 异常值）先写总量等式 T = 2S + x，把"枚举谁"变成"已知谁推谁"
- 用"先删候选再查频次"处理"下标必须不同"的同值情况，比特判 S == x 更简洁
