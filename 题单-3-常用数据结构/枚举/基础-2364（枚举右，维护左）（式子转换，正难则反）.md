**题意：**
*给你一个下标从 **0** 开始的整数数组 `nums` 。如果 `i < j` 且 `j - i != nums[j] - nums[i]` ，那么我们称 `(i, j)` 是一个 **坏***数对** 。*

*请你返回 `nums` 中 **坏数对** 的总数目。*

**核心思路：**
*对于式子 "j-i!=nums[j]-nums[i]" 进行转换 变为：nums[j]-j!=nums[i]-i 有点类似于数学中的整体换元思想 将含有相同未知数的式子分别放一边 最后题目的解法就类似于1512.好数对的数目* 
*不过需要进行正难则反转换*

- *题型模式：枚举右，维护左 + 式子转换 + 正难则反*
- *关键推导：坏数对 ⇔ nums[i] − i != nums[j] − j（同 key 就是好数对）*
- *直接正着算：遍历到 j 时，前面 j 个数对里坏的有 j − cnt[key] 个，累加即可*

两种思路代码：
1.直接算：

```cpp
class Solution {
public:
    long long countBadPairs(vector<int>& nums) {
        long long ans = 0;
        unordered_map<int, int> cnt;
        for (int j = 0; j < (int)nums.size(); ++j) {
            int key = nums[j] - j;
            ans += j - cnt[key];   // 前面 j 个里 key 不同的都是坏数对
            cnt[key]++;
        }
        return ans;
    }
};
```

2.正难则反（总对数 - 好数对）：

```cpp
class Solution {
public:
    long long countBadPairs(vector<int>& nums) {
        int n = nums.size();
        long long total = 1LL * n * (n - 1) / 2;
        unordered_map<int, int> cnt;
        for (int i = 0; i < n; ++i) {
            cnt[nums[i] - i]++;
        }
        long long good = 0;
        for (auto& [k, c] : cnt) {
            good += 1LL * c * (c - 1) / 2;   // c*(c-1) 会超 int，必须 1LL 乘
        }
        return total - good;
    }
};
```

复杂度：O(n) 时间 / O(n) 空间

踩坑/细节：
- 答案最大约 5e9（n = 1e5），必须用 long long；哈希表计数用 int 即可
- key = `nums[i] - i` 的范围约 [-1e5, 1e9]，int 装得下
- 边界输入：单元素（返回 0）、全相同（全部坏数对）、严格递增（全部好数对，返回 0）
- "直接算"版本每个数对只在处理较大下标 j 时统计一次，不重不漏
