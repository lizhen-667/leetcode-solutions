题意：
**从数组中选两个下标不同的数，它们的数位和相等，求这两个数之和的最大值。如果没有这样的数，返回-1。**

解决该题的一个关键点是：
明确数位和的范围 由于1<=nums[i]<=10^9
当某一个数的数位和最大 可以知道该数为“999999999”
当某一个数的数位和最小 可以知道该数为“1”
所以数位和的范围为1-81

解决该题的一个整体思路还是：枚举右，维护左

对于右边枚举的nums[j] 从已经遍历过的左边元素nums[i]中找和它数位和相等的元素 并且用它们的和nums[i]+nums[j]更新最大值
然后用当前遍历的元素与左边元素中位数和相同的元素进行比较 更新最大值

int ans=-1;
vector<int> mx(82,INT_MIN);

for(int num:nums){
int s=0;
for(int x=nums;x;x/=10){
s+=x%10;
}
ans=max(ans,num+mx[s]);
mx[s]=max(num,mx[s]);
}

return ans;
