**题意：**

给定一个整数数组 nums（长度 3 ≤ n ≤ 10⁵，元素 0 ≤ nums[i] ≤ 10⁵），统计满足以下条件的下标三元组 (i, j, k) 的数量：

- 下标严格递增：0 <= i < j < k < n
- nums[i] == 2 * nums[j] 且 nums[k] == 2 * nums[j]

即以 j 为中间位，左右两边的元素都恰好是 nums[j] 的两倍。结果对 10⁹ + 7 取模返回。

**注意：** 三元组按下标计数，值相同的不同位置算不同的三元组；0 的特殊情况（0 * 2 = 0），值为 0 的元素互相也满足条件，不能漏算。

**核心思路：**

- 题型模式：枚举中间 + 前缀/后缀频次统计
- 对每个固定中间下标 j：i 只能在 j 左边、k 只能在 j 右边，两边条件相互独立 → j 的贡献 = 左边值等于 2*nums[j] 的个数 × 右边值等于 2*nums[j] 的个数
- 用 suf 记录 j 右边每个值的频数（先完整扫一遍初始化），pre 记录 j 左边每个值的频数（遍历过程中维护）
- 第二遍遍历，对每个 x（作为中间值）：先 `suf[x]--`（保证 suf 只含下标 > j），再 `ans += pre[2*x] * suf[2*x]`，最后 `pre[x]++`（保证 pre 含下标 <= j）；顺序不能乱
- 把"同时找两个"拆成"左右各找一个"，避免 O(n²) 枚举

**代码：**

```cpp
class Solution {
public:
    int specialTriplets(vector<int>& nums) {
        const int MOD = 1'000'000'007;
        int maxV = 0;
        for (int x : nums) maxV = max(maxV, x);

        vector<int> pre(2 * maxV + 1), suf(2 * maxV + 1);
        for (int x : nums) suf[x]++;

        long long ans = 0;
        for (int x : nums) {
            suf[x]--;                                          // 右边只留下标 > j 的元素
            ans = (ans + 1LL * pre[2 * x] * suf[2 * x]) % MOD; // 当前 j 的贡献
            pre[x]++;                                          // 左边含下标 <= j 的元素
        }
        return (int)ans;
    }
};
```

若想用 unordered_map 版（值域较大时），把两个数组换成 `unordered_map<int, int>` 即可，逻辑完全相同：

```cpp
const int MOD = 1'000'000'007;

unordered_map<int, int> suf;
for (int x : nums) suf[x]++;

unordered_map<int, int> pre;
long long ans = 0;

for (int x : nums) {
    suf[x]--;
    ans = (ans + 1LL * pre[2 * x] * suf[2 * x]) % MOD;
    pre[x]++;
}
return (int)ans;
```

**复杂度：** O(n) 时间 / O(值域) 空间（数组版），O(n) 空间（map 版）

**踩坑/细节：**
- int 溢出：pre[2*x] 与 suf[2*x] 之和 ≤ n-1，乘积最大 (n-1)²/4 ≈ 2.5×10⁹，仍超 int 上限 2,147,483,647，必须用 long long 相乘；"每个计数都能到 10⁵"是宽松上界，10¹⁰ 不可能同时取到
- ans 累加：总答案最大约 n³/6 ≈ 1.7×10¹⁴，long long 才装得下；每步取模后 return 前已保证小于 MOD，再转 int
- 顺序不能乱：先 `suf[x]--` → 计算 → `pre[x]++`；当 x = 0 时 2*x = x，顺序错了会把 j 自己算进贡献
- unordered_map 的 operator[] 访问不存在的键会自动插入 0，不影响正确性但会塞多余键；本题值域已知（2*x ≤ 2×10⁵），数组更快
- 笔误：unordered_map<int.int>、全角分号这类直接编译错误

**方法提炼：**

- 枚举中间元素的题型：贡献 = 左边满足条件个数 × 右边满足条件个数，左右独立即可拆分
- 用"先删后算再加"的增量维护避免重复扫描，把 O(n²) 降到 O(n)
- 两端计数互为约束时，乘积上界要按"和固定"算（均值不等式），不能拿两个独立上界相乘
