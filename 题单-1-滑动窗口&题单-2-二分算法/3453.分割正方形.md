输入：一个3维整数数组 int squares
输出：最小的y坐标 double y

设这条线刚开始在最下面即与坐标轴重合 然后不断往上移 我们要找的满足条件的y就是 这条线以下的正方形的面积为总的1/2即可
关键在于面积的计算：
1.对于完全在这条线之下的正方形
即(yi<y)
需要补充的面积为：
li²
对于在这条线中间的正方形
需要补充的面积为：
(y-yi)*li

思路：
先for循环遍历求出总的面积total
然后我们要求的y线下的标准面积为target=total/2

然后通过二分法来不断逼近目标值target

又因为答案如果与实际答案的误差在 `10-5` 以内，将视为正确答案。
因为yi的范围为[0,10的9次方]
则我们需要二分的次数设为x  10的9次方/2的x次方<=10的-5次方
所以2的x次方>=10的14次方
所以x大约为50左右即可满足要求


double sum=0;
for(auto&sq;squares){
sum+=(long long)sq[2];
}
double target=sum/2;

double R=2000000000;
double L=0;
for(int i=0;i<50;i++){
double mid=L+(R-L)/2;
double below=0;

for(auto& sq:squares){
long long x=sq[0],y=sq[1],l=sq[2]
if(mid>=y+l){
below+=(double)l*l;
}
else if(mid>y){
below+=l*(mid-y);

}
if(below<target){
L=mid;
}
else{
R=mid;
}

}
return L;

}
