### 题意

  正方形中心在 (0,0)，边平行坐标轴。找包含点数最多且标签不重复的正方形，返回最大点数。

解题方法一：二分间接值
由于正方形边长越大，越不合法，有单调性，所以可以二分边长的一半。

在二分中统计遇到的字符，如果没有遇到重复的字符，说明正方形合法，用字符个数更新答案的最大值。

核心函数：
abs()函数 :abs(x)返回x的绝对值

__builtin_popcount(): 是一个统计二进制1的个数的函数

核心代码：
auto check=[&](int size)->bool{
        
        int vis=0;
        
        for(int i=0;i<n;i++){

            if(abs(points[i][0])<=size&&abs(points[i][1])<=size){

                int c=s[i]-'a';

                if(vis>>c&1){

                    return false;

                }

                vis|=1<<c;

            }

        }

          ans=__builtin_popcount(vis);

          return true;

        };

解释：vis>>c&1 vis右移c个二进制位 用于做比较 判断c是否在之前已经出现过

vis|=1<<c; 将1左移c个二进制位 并将左移后的结果与vis相或 用于记录c已经出现过
vis中第c位的数字为1
