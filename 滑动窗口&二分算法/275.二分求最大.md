由题意可知h指数一定要取最大值 如果不取最大值 那么这个h指数值就不唯一 而答案只能是一个唯一值
所以题意就是：求n篇论文中h篇论文的引用数>=h的最大h值

题目所给条件有：
1.citations为升序排列

要求：
1.算法时间复杂度为log n

解题思路：
设满足条件的最小下标的论文的下标为i
则有citations[i]>=h;
n-i=h;
即可以推导出
citations[n-h]>=h;
找最大的h 

所以可以用2分算法 因为h的范围为[0,n]
所以n-h的范围也为[0,n]

所以可以让二分的 左右指针 分别为
int left=0;
int right=n;
wihile(r>=l){
int mid=l+(r-l)/2;
if(citations[mid]>=n-mid){
r=mid-1;
}
else{
l=mid+1；
}
}
return n-l;
